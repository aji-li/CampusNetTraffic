# CAUCNet Traffic

CAUCNet Traffic 是一个面向 Windows 的 CAUC 校园网流量助手，用于查看本机实时流量、同步校园网后台数据、查看在线设备，并提供托盘常驻和轻量悬浮流量窗。

当前版本：v1.0.0

## 功能

- 实时显示本机下载/上传速度
- 统计本次打开 APP 后的总流量
- 同步校园网后台的已用流量、可用流量、余额、套餐和计费周期
- 自动复用校园网登录会话，过期后再提醒重新登录
- 查看当前在线设备列表，可一键注销设备
- 今日/本月本机流量统计
- 最近 10 分钟趋势图、最近 7 天流量柱状图
- 托盘常驻，右键菜单显示状态、用量和网速
- 可选任务栏上方迷你流量窗
- 单实例运行：重复打开会激活已有窗口
- 同步失败自动退避，避免后台不可达时频繁请求
- 校园网自动同步间隔可配置：15 / 30 / 60 / 120 秒
- 迷你流量窗位置记忆
- 可清空本机流量统计数据库
- 开机自启、阈值提醒、日志导出
- 剩余流量、余额、本次用量提醒可独立开关
- 校园网会话过期时托盘通知提醒重新登录
- 首次使用引导：提示网页登录、同步校园网和托盘常驻
- 一键导出诊断包，包含日志、崩溃记录、设置摘要和系统信息，并自动脱敏账号、Cookie、IP、MAC
- 本地设置和会话数据存放在用户目录，不保存明文密码

## 运行环境

- Windows 10 / 11
- WebView2 Runtime

> Windows 11 通常已经自带 WebView2 Runtime。如果打不开内嵌网页登录页，需要安装 Microsoft Edge WebView2 Runtime。



## 使用方式

1. 运行 `CAUCNetTraffic.exe`
2. 点击“网页登录”
3. 在内嵌页面完成校园网登录
4. 登录成功后点击“同步校园网”
5. 后续打开 APP 会自动复用登录状态，过期后才需要重新登录

## 常用设置

- “开机自动启动”：在设置页打开或关闭
- “显示任务栏上方迷你流量窗”：默认关闭，可在设置页或托盘菜单打开
- “校园网自动同步间隔”：可调节后台同步频率
- “提醒阈值”：可单独开关剩余流量、余额、本次用量提醒
- “清除校园网登录状态”：会清除本地保存的会话和 WebView cookie
- “清空本机流量统计”：删除本机历史统计数据，不影响登录状态
- “导出诊断包”：出现问题时可导出 zip 包用于排查，导出内容会自动脱敏
- “重新打开首次使用引导”：重新查看新用户配置步骤
- “检查更新”：读取设置页中的更新源 `latest.json`，自动比较版本并打开下载链接

## 本地数据位置

程序数据默认保存在：

```text
%LOCALAPPDATA%\CampusNetTraffic
```

其中包括：

- `settings.json`：本地设置
- `traffic.db`：本机流量统计数据库
- `app.log`：运行日志
- `crash.log`：崩溃日志

## 项目说明

本项目当前主要面向 CAUC 校园网环境，校园网登录和后台同步逻辑针对 `https://www.cauc.edu.cn/Self/dashboard` 实现。
